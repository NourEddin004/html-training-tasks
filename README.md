# HTML Training Tasks

This repository contains three HTML practice tasks completed as part of my web development training.  

Each task focuses on different HTML concepts, including forms, lists, and tables.

## Tasks

## Task 1: Registration Form 

A simple registration form that demonstrates the use of HTML forms and input elements.

### Concepts Practiced:

- Form structure

- Text inputs

- Email input

- Radio buttons

- Dropdown menu (`select` and `option`)

- Labels

- Submit button

- Fieldset grouping

---

## Task 2: Nested Lists 

A nested list example that demonstrates different types of ordered and unordered lists.

### Concepts Practiced:

- Unordered lists (`ul`)

- Ordered lists (`ol`)

- Nested lists

- List styling

- Different numbering formats:

  - Roman numerals

  - Alphabetical numbering

  - Reversed lists

---

## Task 3: HTML Table 
A table example demonstrating how to organize data using rows, columns, and merged cells.

### Concepts Practiced:

- Creating tables

- Table rows (`tr`)

- Table cells (`td`)

- Row spanning (`rowspan`)

- Column spanning (`colspan`)

- Table borders
